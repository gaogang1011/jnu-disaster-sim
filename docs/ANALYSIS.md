# 대피소 구성별 대피 거리 분석

`npm run analyze`로 다시 만들 수 있습니다. 캠퍼스 안 건물 59동의 출입구(외곽선 각 변의 가운데)에서 OSM 보행 그래프를 따라
가장 가까운 대피소까지의 최단 거리를 구하고, 건물 면적으로 가중 평균했습니다. 도보 속도는 1.4m/s입니다.
혼잡과 침수·화재 같은 위험은 반영하지 않은 **최단 거리 기준**이므로, 실제 대피 시간은 시뮬레이터 결과처럼 더 길어집니다.
