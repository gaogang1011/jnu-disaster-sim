# 설계: 재난 대응·대피 시뮬레이터로 전환

1차 버전은 "재난으로 캠퍼스를 부수는 체험"에 가까웠다. 2차 버전은 같은 3D 캠퍼스 위에서 다음 질문에 답하는 도구로 바꾼다.

> **제주대 아라캠퍼스에서 재난이 나면 어디가 위험하고, 사람들은 어디로 어떻게 대피해야 하며, 대피는 얼마나 걸리는가?**

## 1. 목표

| 목표 | 확인 방법 |
|---|---|
| 재난별로 위험한 건물·구역을 색으로 보여준다 | 위험 등급 4단계 색상, 위험 평가표 |
| 재난 종류에 맞는 대피 장소로 실제 길을 따라 대피시킨다 | 보행 그래프 위 최단 경로, 대피소 도착 |
| 위험 구역(침수·화재·낙하물)을 피해 경로를 다시 찾는다 | 경로 비용에 위험 반영, 주기적 재탐색 |
| 대피 결과를 수치로 비교할 수 있다 | 대피 완료율·평균/최대 시간·고립·위험 노출, 실행 기록표 |
| 공식 행동요령을 함께 익힌다 | 재난별 행동요령 카드(출처 표기) |

파괴 연출(폭발, 건물 붕괴, 파편 비산)은 줄이고, 공격·무기 성격의 시나리오는 넣지 않는다.

## 2. 재난 구성 (6종)

| 키 | 재난 | 강도 슬라이더 1~10이 뜻하는 실제 값 | 대피 방식 | 대피 시작 시점 |
|---|---|---|---|---|
| 1 | 지진 | 규모 M = 4.0 + 0.35×강도 (4.35~7.5) | 넓은 옥외 공간 | 흔들림이 멈춘 뒤 (그 전에는 제자리 몸 보호) |
| 2 | 지진해일 (가정) | 정문 기준 수위 = 3.8×강도 − 3.6 m | 고지대 | 경보 즉시 |
| 3 | 집중호우 침수 | 시간당 강수량 = 30 + 12×강도 mm | 고지대 | 경보 즉시 |
| 4 | 태풍 | 최대풍속 = 22 + 3.5×강도 m/s → 기상청 강도(중·강·매우강·초강력) | 튼튼한 실내 | 즉시 |
| 5 | 화재 | 발화 범위, 풍속 | 넓은 옥외 공간 (불에서 먼 곳) | 즉시 |
| 6 | 한라산 분화 | 화산탄 낙하 범위, 지속 시간 | 튼튼한 실내 | 즉시 |

제외: 폭탄 투하, 위성 추락, 유성우, 토네이도.

아라캠퍼스는 해발 약 36~124m여서 실제 지진해일이 닿을 가능성은 매우 낮다. 지진해일은 **가정 시나리오**로 표시한다.

## 3. 위험도 모델

건물은 OSM 외곽선을 26m 격자로 나눈 구역 단위로 피해량 `d = 1 − hp/maxHp`를 가진다(1차 버전 모델 재사용). 무너뜨리지 않고 등급으로 바꿔 보여준다.

| 등급 | 조건 | 색 |
|---|---|---|
| 0 안전 | d < 0.15 | 원래 외벽 |
| 1 주의 | d < 0.40 | 노랑 |
| 2 경고 | d < 0.70, 또는 화재 중, 또는 침수 0.5m 이상 | 주황 |
| 3 위험 | d ≥ 0.70 | 빨강 |

건물마다 가장 큰 피해 원인(지진 흔들림·침수·화재·강풍·화산탄)을 기록해 위험 평가표에 함께 보여준다. 위험 등급 3인 건물은 실내 대피소로 쓰지 않는다.

## 4. 대피 경로

**그래프**: OSM 도로·보행로 116개(차도 포함, 보행자는 차도로도 걷는다고 가정)의 꼭짓점을 1m 격자로 맞춰 노드로 만들고, 25m보다 긴 구간은 잘게 나눈다. 다른 길이 교차점 꼭짓점을 공유하지 않는 경우를 대비해 8m 이내 노드끼리 연결한다.

**대피소 연결**: 대피소마다 반경 60m 안의 가까운 노드 4개와 직선 간선으로 잇는다.

**탐색**: 사용 가능한 대피소 전체를 출발점으로 하는 **다중 출발 다익스트라**를 거꾸로 한 번 돌려, 모든 노드에 "가장 가까운 대피소까지 남은 거리"와 "다음 노드"를 기록한다. 사람 수와 상관없이 탐색은 한 번이며, 각자는 다음 노드를 따라가기만 한다.

**위험 반영 비용** (1.5초마다 다시 계산):

| 위험 | 간선 비용 |
|---|---|
| 침수 깊이 0.3m 초과 | 통행 불가 |
| 침수 0.1~0.3m | ×4 |
| 불타는 건물·나무 15m 이내 | 통행 불가 |
| 불 40m 이내 | ×3 |
| 위험 등급 2·3 건물 10m 이내 (낙하물) | ×2.5 / ×5 |

대피소 자체가 침수되거나 불 60m 이내이거나(옥외), 건물이 위험 등급 3이면(실내) 그 대피소는 자동으로 닫힌다. 사용자가 대피소를 직접 끄고 다시 실행해 결과를 비교할 수 있다.

## 5. 대피자 모델

- 표본 320명(저화질 180명). 85%는 건물 출입구(외곽선 바깥 2m)에서, 15%는 길 위에서 시작. 건물 면적에 비례해 배치.
- 상태: 평상시 → 반응 대기(0.5~4초) → 대피 중 → 도착 / 고립.
- 길 위로 들어갈 때는 `직선 거리 × 1.2 + 노드의 남은 거리`가 가장 작은 노드를 고른다.
- 보행 속도 1.4m/s, **시간 10배 압축**(화면 1초 = 실제 10초). 화면의 시간 지표는 모두 실제 시간으로 환산해 표시한다.
- 혼잡: 간선 위 인원이 수용량(길이/3명, 최소 4명)을 넘으면 속도가 최대 30%까지 줄어든다. 간선별 누적 통행량으로 병목을 색으로 보여준다.
- 깊이 0.5m 넘는 물에 갇히거나 갈 수 있는 대피소가 없으면 고립, 불 12m 이내나 물 0.2m 이상을 지나면 위험 노출로 센다.

## 6. 결과 지표

대피 완료율, 대피 중·도착·고립 인원, 위험 노출 인원, 평균·최대 대피 시간(실제 환산), 대피소별 도착 인원. 모두 끝나거나 시간이 다 되면 **실행 기록표**에 한 줄씩 쌓는다.

## 7. 화면 구성

왼쪽 패널 (위에서 아래로)

1. 제목·경과 시간·진행 중인 재난
2. 시나리오 버튼 (한 번에 재난·강도·위치·시간대 설정)
3. 재난 선택 6종 + 설명
4. 강도 슬라이더 + 실제 단위
5. 대피 현황 (완료율 막대, 지표 6개)
6. 대피소 목록 (켜기/끄기, 도착 인원, 닫힘 사유)
7. 위험 평가 (등급별 건물 수, 위험 건물 상위 5개와 원인)
8. 행동요령 카드 (출처 링크)
9. 실행 기록표
10. 상황 기록

오른쪽 위 토글: 시간대, 추적 카메라, 슬로 모션, **위험도 색상**, **대피 경로**, 소방 출동, 이름표, 소리, 초기화.

## 9. 테스트

- `npm test` (Node): 대피소가 캠퍼스 안에 있는지, 그래프가 연결되어 있는지, 캠퍼스 안 노드의 90% 이상이 대피소에 닿는지, 통행 불가 간선을 피해 가는지.
- `npm run test:e2e` (헤드리스 크롬): 재난 6종 시작, 지진에서 위험 등급 건물 발생, 대피자가 실제로 대피소에 도착하는지, 대피소를 끄면 다른 대피소로 가는지, 복구, 스크립트 오류 없음.

## 10. 119 대응 (4차)

3차까지는 구조대가 **고립자가 생겼을 때만** 출동했습니다. 고립은 대부분 물 때문에 생기므로 지진·태풍·화산에서는 구조대가 거의 보이지 않았고, 소방차는 정문에서 바로 나타나 따로 집계되지 않았습니다. 실제로는 재난이 나면 신고가 들어가고 소방차·구조대가 함께 출동하므로 다음처럼 바꿉니다.

### 출동

- 재난이 시작되면 바로 **119 신고 → 출동**합니다. 소방차와 구조대 모두 5분(실제 환산, 가정) 뒤 정문·후문 중 안전한 쪽(침수·불이 없는 쪽)으로 도착합니다.
- "소방·구조 출동" 토글을 끄면 출동하지 않습니다. 같은 재난을 켜고 끈 상태로 실행해 결과를 비교할 수 있습니다.

### 재난별 임무

| 재난 | 소방차 | 구조대 |
|---|---|---|
| 지진 | 가스 화재 진압 | 위험 건물에 갇힌 사람 수색·구조, 위험 건물 안전 점검 |
| 지진해일·호우 | (불이 없으면 대기) | 침수 고립자 구조 |
| 태풍 | 낙뢰 화재 진압 | 위험 건물 갇힘·고립자 구조, 위험 건물 안전 점검 |
| 화재 | 화재 진압 | 불에 길이 막힌 사람 구조 |
| 한라산 분화 | 화산탄 화재 진압 | 위험 건물 갇힘 구조, 위험 건물 안전 점검 |

구조대가 하는 일의 우선순위는 **고립자 구조 → 위험 건물 안전 점검 → 대기**입니다. 점검은 위험 등급 2 이상 건물을 위험도가 높은 순으로 1동씩 확인합니다(1분, 실제 환산).

### 고립 유형 추가: 건물 안 갇힘

- 대피를 시작하기 전(몸 보호·반응 대기 중)에 있던 건물이 **위험 등급 3**이 되거나 불이 붙으면, 그 건물에서 출발할 사람 중 일부(20%)가 **건물 안에 갇힌 것**으로 처리합니다.
- 물 고립과 달리 스스로 빠져나오지 못하고 구조대가 와야 나옵니다. 구조대는 수색에 2분(실제 환산)을 쓴 뒤 데리고 나와 가장 가까운 열린 대피소로 옮깁니다.
- 사망 상태는 만들지 않습니다. 구조 출동을 끄면 끝까지 "고립"으로 남습니다.

### 지표와 화면

- 대피 현황에 **119 대응** 줄: 도착까지 남은 시간 → 소방차 대수·진압한 곳 수, 구조 인원·평균 구조 대기, 점검한 건물 수.
- 실행 기록표에 "진압" 열 추가.
- 고립 사유별 인원(물, 길 막힘, 건물 안)을 툴팁·로그로 구분합니다.

### 테스트

- 재난 6종 모두에서 119가 출동해 도착하는지.
- 지진에서 건물 안 갇힘이 생기고 구조대가 구조하는지, 출동을 끄면 구조되지 않는지.
- 화재에서 소방차가 진압한 곳이 1곳 이상인지.
